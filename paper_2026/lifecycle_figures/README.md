# Lifecycle, framework comparisons and current figure sources

This component supplies the executed lifecycle definitions, frozen cohort identifiers, framework and stage-comparison drivers, their saved inputs, and the figure sources associated with the November 2026 manuscript. See `figure_map.csv` for all 8 main figures and 42 supplementary figures. The five newer analysis figures are generated by the adjacent `../newanalyses` component.

## Scientific scope

The frozen primary cohort contains 2,340 unique SID with framework genesis in 1982–2023. IBTrACS v04r01 `USA_WIND` is a one-minute sustained wind estimate in knots; records are sampled at 00, 06, 12 and 18 UTC. `lifecycle/ibtracs_prepare.py` provides the original preparation rules, including its isolated internal six-hour wind-gap handling. The current E boundary is the 25% progress threshold between initial wind and lifetime maximum intensity. It has no additional 24-hour intensification gate. The compatible `escalation_rate_threshold` argument occupies its original positional slot but is ignored. Other diagnostic rates remain defined for their own purposes.

The current lifecycle implementation is `lifecycle/lifecycle_core.py`. Internal `Res`/`resolution_*` identifiers remain stable machine identifiers; publication labels are Decay/Dec. The lifecycle function alone does not define the final 2,340-SID analysis cohort: the supplied frozen SID set also reflects the approved common-support and risk-set requirements. `lifecycle/input/main_sid_eligibility_ledger.csv` records that restriction. Diagnostic subsets retain their own support requirements. `lifecycle/representations.py` preserves the distinct continuous near-peak, occupied near-peak and full F representations.

## Environment and saved inputs

Use the repository environment file. This component requires NumPy, pandas, SciPy, statsmodels, PyArrow, psutil, Matplotlib, Pillow, pyshp and Shapely. The figure code records its own style and export settings. Arial is used where specified by the accepted source; a font license is not included. Install a legitimate copy to match that typography. Rendering on a different platform or font installation may change text metrics.

The release assets supply the larger processed tables, fixed bootstrap multiplicities, numeric arrays and high-resolution layout inputs at the paths declared by the release manifest. Extract the assets into the repository before using the saved-input paths. They contain processed research inputs, not a copy of the complete ERA5 archive. The root README describes IBTrACS and ERA5 acquisition, variables, units, pressure levels and the broader production workflow.

## Bounded checks

From the repository root:

```bash
python -B paper_2026/lifecycle_figures/validate_saved.py --output work/lifecycle_validation.json
python -B paper_2026/lifecycle_figures/verify_frozen_lifecycle.py
```

These checks verify 2,340 unique frozen SID, 63,769 current records, 133 return events from 123 SID, 45 exact scientific fields from three real frozen cyclone tracks, source syntax and dependency files, stored figure-input hashes, the threshold-grid input hashes, and the saved seven-test primary-trend BH family. They do not refit models, generate resamples, read ERA5 or redraw figures. The seven-test check is a separate family from the later standardized-duration 16-test family supplied in the history component.

## Starting from the raw best-track snapshot

The existing public command and function interfaces are retained. The current root configuration binds the updated lifecycle core and the current frozen SID and record tables. For one supplied frozen SID:

```bash
python -m src.raw_workflow.lifecycle --ibtracs data/ibtracs.ALL.list.v04r01.csv --sid 1982005S10105 --out work/lifecycle_one
```

Choose an SID from `lifecycle/input/main_sid.txt`; the example above is only valid if present in that file. Use `--all-frozen` instead of `--sid` for the complete frozen cohort. The command requires the exact IBTrACS snapshot checksum in `config/raw_inputs.json`, preserves the existing quality-control rules, and compares recomputed fields with the frozen records. A different current online IBTrACS revision is not substituted silently. `--out` must be a new directory. The original function remains callable independently with its original return structure.

## Starting from saved processed inputs

Copy `framework` to a separate working directory before running its drivers; preserve its relative tree. These are the actual executed drivers, adapted only for portable paths and platform-specific process priority. Their estimation functions and numerical settings are retained. They write scientific outputs and completion receipts in the copied `unified/statistics` and `unified/reports` directories.

1. `unified/scripts/recompute_framework_and_raw_stages.py`: framework chronology allocation, alternate representations, environment discrimination and raw stage comparisons, restricted to the frozen master cohort. It reads saved framework rows and the original comparison inputs.
2. `unified/scripts/refit_adjusted_stages.py`: adjusted stage comparisons, reading the saved stage table and fixed SID-multiplicity bank. The reference estimates are in `reference/stage_adjusted`.
3. `unified/scripts/recompute_primary_summaries.py`: cohort and basin summaries, original primary temporal statistics and the complete threshold-sensitivity grid. It reads frozen lifecycle outputs and the 18 stored threshold configurations. Historical global-return estimates in the newer manuscript are supplied by `../newanalyses`; the older primary family here is preserved with its original identity.

The drivers retain their original completion guards. Do not remove a completed receipt to overwrite accepted outputs; work in a fresh copy. Full execution performs the original estimations and can be costly. Release validation did not execute those campaigns.

`framework/scripts/reclassify_thresholds.py --out work/threshold_grid` also supplies the actual eighteen-configuration classification loop, reading the original prepared candidate tracks and current lifecycle function. It checks each generated QC, summary and observation table against the saved current output. The original candidate pool covers 1982–2025; the downstream manuscript summaries restrict it to the frozen 1982–2023 cohort. This preserves the executed preparation chain and does not extend the manuscript study period. The baseline branch reads its accepted classification as in the original driver. Only `--help` and source/dependency checks were run for this release.

## Figures and editable sources

The `figures/Figure_*` directories use current manuscript numbering. Each of the 45 included packages contains its actual plotting entry, frozen numeric input, configuration, scientific-object baseline where required, and all local runtime helpers. `figure_map.csv` identifies the five adjacent new-analysis entries and the original internal output stems. Internal stems and hook identifiers are deliberately retained, because they select the accepted plotting logic; use the map when assigning a regenerated output to the current manuscript number.

For an individual plotting package:

```bash
python paper_2026/lifecycle_figures/figures/Figure_03/run.py --output-dir work/figure_03 --dpi 900
```

The default is 900 dpi and the entry rejects dpi below 600. Plotting consumes the supplied frozen results and does not rerun the underlying ERA5 diagnostics. Main Figure 8 includes its editable Python/vector-object scene and export entry. Main Figure 1 and Supplementary Figure 1 preserve their explicit shared illustrative history. Each package's `inputs.json` or `manifest.json` records the relevant input files and quantities.

The final six compact layouts (main Figure 7; Supplementary Figures 5, 6, 7, 8 and 31) use the separately preserved accepted high-resolution bases in `layout/backup`. Their actual lossless crop/composition entries are:

```bash
python paper_2026/lifecycle_figures/layout/agents/group_a/compose.py
python paper_2026/lifecycle_figures/layout/agents/group_b/compose_layouts.py
python paper_2026/lifecycle_figures/layout/agents/group_c/compose_layout.py
```

They move complete existing raster panels and preserve the accepted pixels; they do not estimate values or redesign subplots. Outputs are written beneath the respective group directory. The corresponding original scientific plotting sources remain available through `figure_map.csv`. The accepted PNG checksums in that map bind the publication assets used for source tracing; they do not promise cross-platform pixel identity after plotting anew.

## Validation boundary

The release audit checked all 45 plotting entries with `--help`, parsed their Python sources, verified packaged frozen-input hashes and resolved local helper dependencies. All 50 current figure sources were traced; the six final crop/composition entries and their original image inputs are retained. No figure was redrawn and no full ERA5, MWT, bootstrap or model-fitting campaign was rerun for the release. Validation of a complete scientific rerun remains separate from these bounded release checks.
