# v2.1.6 — Land-contact sensitivity

This release adds a retrospective land-contact sensitivity check to the v2.1.5 statistical archive. Supplementary Data 1 includes the return-event track ledger, restrictions on the paired diagnostic samples and all six estimates with their 95% cyclone-bootstrap intervals.

- Moisture exchange uses the same −24 to +24 h track window around each paired departure. Both members had to have complete coverage and no identified centre contact. The unadjusted comparison retains 75 of 80 original pairs.
- Energy contrasts use the complete trough-to-return and final-decay stages of the original wind-matched units. The restricted sample comprises 71 cyclones, 74 return events and 110 event–wind-bin pairs. The two stages can differ in duration.
- In the 54-pair adjusted moisture design in Table S3, the zero land-contact covariate describes five six-hourly centre records from −24 h through departure. The event ledger supplies the separate track-window classifications.

The workbook and CSV package retain the original statistical entries and identifiers. The replay package includes the track fields, cached matched values, bootstrap settings and a Python entry point. The existing [six main and ten supplementary figures](https://github.com/qq492947833/tc-near-peak-moisture/releases/tag/figures-20261125-fig6-r02) retain their separate presentation version.
