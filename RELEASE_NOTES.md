# v2.1.4 — Selected supplementary evidence and data index

The reading set now contains eight main and 17 selected supplementary figures. Overlapping series have one graphical home; frozen results and their original inferential families remain in the accompanying data. Figure 4 retains the original paired net-inward estimates and their 95% intervals; Supplementary Figure 13 distinguishes event-specific integrals from Fig. 6e rates. No ERA5 processing, model fitting or resampling was performed.

The release provides both publication formats and the native source panels used by the versioned composition script. The manuscript documents are distributed separately.
